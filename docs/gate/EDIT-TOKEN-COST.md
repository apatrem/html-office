# Token cost of an edit on the example decks

Generated by `node tools/gate-bench/edit-cost.mjs`; do not edit by hand (`--check` fails on a stale copy). Part of the measurement kit of [ADR-016](../decisions/016-slides-go-stop-gate.md) §8.

Before it changes a deck, an assistant reads the deck's content. The skill tells it to read the output of `deck.mjs extract` (the content zone, without cached chart pictures or embedded images) and, when present, the guide embedded in the file. The table gives the size of each for the two decks distributed with the skill (html-slides 0.7.2).

| Deck | Slides | Whole file | Whole file, tokens | `extract` output | `extract` output, tokens | Embedded guide | Embedded guide, tokens |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `community-garden.html` | 9 | 563,765 bytes | 194,726 | 8,050 bytes | 2,531 | 31,371 bytes | 9,288 |
| `catalogue.html` | 18 | 573,214 bytes | 198,011 | 12,329 bytes | 3,948 | 31,371 bytes | 9,288 |

- **Tokens are a proxy.** They are counted with `gpt-tokenizer` 4.0.3, encoding `o200k_base`, the tokenizer pinned in `tools/engine-assessment`. It is OpenAI's encoding, not Claude's: Claude's own count for the same text differs. The figures compare the three readings with each other; the measured cost of an edit is the usage that the editing sessions of the bench report.
- **Whole file** is what reading the `.html` directly would cost. Most of it is the editor engine (495,310 bytes); no step of the skill asks for it.
- **`extract` output** is what an edit needs: about 281 tokens per slide for `community-garden.html` and 219 for `catalogue.html`.
- **Embedded guide** is the same text in every deck of a given engine version. An assistant that already has the skill does not need to read it; one that only has the file does, once.
- The skill's own instructions and references, and the screenshots the assistant looks at before and after an edit, are not in this table: they are part of the measured sessions.
