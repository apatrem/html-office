# 3 2027 plan

The plan keeps the current sites and opens two more in the south region, <mark>subject to the spring survey</mark>. A [public summary](https://example.org/northwind-plan) is available.

- Open two sites in the <u>south</u> region
- Train volunteers
  - Spring cohort
  - Autumn cohort

> Grow where the soil is already rich.

Each forecast applies `growth` to the 2026 base:

```
forecast = base × (1 + growth)
growth   = 0.12
```
